# 🧭 LangChain 生态模块地图

> 所有笔记和代码都标注了所属模块，对照官网文档结构查阅。
> 官网文档顺序：**Learn（教程）→ LangChain → LangGraph → LangSmith**

## 官网文档结构（docs.langchain.com）

```
LangChain 生态
├── 📘 Learn（教程页）          ← 官方教程，对应 official_tutorials/
├── 🦜 LangChain（langchain 包）
│   ├── langchain_core          ← 核心抽象：messages/prompts/LCEL/output_parsers
│   ├── langchain.agents        ← create_agent 智能体入口
│   └── 集成包                  ← langchain-deepseek / langchain-chroma / langchain-huggingface...
├── 🕸️ LangGraph（langgraph 包）
│   ├── StateGraph              ← 状态图编排
│   └── checkpoint              ← 持久化/记忆
└── 📊 LangSmith（平台）
    ├── tracing                 ← 链路追踪
    └── evaluation              ← 数据集评估
```
