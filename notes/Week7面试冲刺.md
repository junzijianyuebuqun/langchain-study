## 一、12 道高频面试题 + 标准答案

### Q1. LangChain 是什么？解决什么问题？
> 大模型应用开发框架。解决两个问题：
> ① **统一接口**：一套代码切换 OpenAI/DeepSeek/Claude 等任意模型
> ② **组件化抽象**：提示词、输出解析、检索、工具、记忆都变成可组合的积木，用 LCEL 管道拼装

### Q2. LCEL 是什么？相比旧版 Chain 的优势？
> LangChain Expression Language，用 `|` 声明式组合组件：`prompt | model | parser`。
> 优势：写法统一、自动支持流式/异步/批量、可任意嵌套。1.0 已完全取代 LLMChain 等旧 API。

### Q3. 画出 RAG 完整流程？
```
建库：文档 → Loader加载 → Splitter切分 → Embedding向量化 → 存入向量库
问答：提问 → 问题向量化 → 相似度检索TopK → 片段拼入Prompt → 模型生成
```

### Q4. Embedding 原理？余弦相似度？
> Embedding 把文本映射为高维向量，语义相近的文本向量距离近。
> 余弦相似度 = 两向量夹角的余弦值（-1~1），越接近 1 越相似，是检索阶段最常用的度量。

### Q5. chunk_size 和 overlap 怎么选？
> chunk_size 太大：一片多主题，检索不精准；太小：语义不完整。
> 经验：中文 200~500 字。overlap 取 10%~15%，防止一句话被切断。

### Q6. Agent 的 ReAct 循环？
> Reasoning + Acting 循环：思考 → 选工具 → 执行 → 观察结果 → 再思考 → …… → 最终回答。
> 与普通 Chain 的本质区别：流程由模型自主决策，不是写死的。

### Q7. Tool 的三要素？
> name（标识）、description（模型选择工具的唯一依据，决定 Agent 质量）、参数 schema（类型约束）。

### Q8. Chain vs Agent vs LangGraph？
> Chain：流程写死，最可控；Agent：模型全权决定，最灵活；
> LangGraph：你画流程图 + 模型在节点里干活，支持持久化/人工介入/多Agent，生产环境首选。

### Q9. LangGraph 三要素？
> State（共享状态）、Node（读改状态的函数）、Edge（连线，条件边实现分支和循环）。

### Q10. 如何评估 RAG 效果？如何减少幻觉？
> 评估：检索命中率、答案准确率（可用 LangSmith 建测试集自动评估）。
> 防幻觉：① prompt 约束"只根据资料回答" ② 来源引用 ③ 检索质量控制（重排序、阈值过滤）。

### Q11. 流式输出原理？
> 模型边生成边返回 token（SSE 推送），前端逐字渲染。
> LangChain 用 `model.stream()` 逐 chunk 消费。所有聊天产品的打字机效果都是它。

### Q12. 多轮对话记忆怎么实现？
> 模型无记忆，本质是每轮把历史消息列表一起发给模型。
> 进阶：滑动窗口（只留 N 轮）、摘要记忆（旧对话压缩）、LangGraph checkpointer 自动管理。

## 二、项目深挖问题（面试官必追问）

**项目 A（知识库问答）可能被问：**
- 检索不准怎么优化？→ 调 chunk 策略、加 Rerank 重排序、混合检索（BM25+向量）
- 长文档怎么处理？→ 父子文档检索（小片检索、大片喂模型）
- 怎么评估效果？→ LangSmith 建测试集，跑检索命中率和答案准确率
- token 成本怎么控制？→ 控制 k 值、历史消息用摘要压缩、输出限长

**项目 B（研究型 Agent）可能被问：**
- 为什么用 LangGraph 而不用 create_agent？→ 反思-补充搜索的循环流程需要显式控制，LangGraph 状态机更可控、可观测、可持久化
- 怎么防死循环？→ rounds 计数器限最大轮次
- 搜索工具怎么接真实的？→ Tavily/SerpAPI，换 tool 实现即可，图结构不变

## 四、面试应答技巧

1. **先给结论，再展开**："RAG 就是先检索后生成（结论）。具体分建库和问答两个阶段（展开）……"
2. **必带数字**："chunk_size 我一般设 200~500 字"、"k 取 3~5"
3. **主动讲 trade-off**："chunk 太大检索不准，太小语义不全，所以要按文档类型调"——这句话直接体现你做过
4. **不会的问题**："这个我还没深入过，但我了解相关的 XX 是……"（往会的地方引）
